# แบบฟอร์มข้อมูลบริษัท: Backdrop ชุดแรก

- สถานะชุดข้อมูลเต็ม: ยังไม่พร้อมเริ่ม Phase 1F-B รอบที่รวมแรงงานและผิวสำเร็จ
- หมายเหตุ: Phase 1F-B1 ใช้เฉพาะกฎ HMR และไม้โครงที่เจ้าของโปรเจกต์อนุมัติภายหลัง แบบฟอร์มส่วนที่เหลือยังไม่ถือว่าครบ

- เวลาทำงาน: เวลาปกติเท่านั้น
- จำนวนด้าน: 1 ด้าน
- ชุดวัสดุ: วัสดุจริง 1 ชุดที่บริษัทใช้ประจำ

## เกณฑ์พร้อมเริ่ม Phase 1F-B

- [ ] Method และเงื่อนไขการใช้งานได้รับอนุมัติ
- [ ] วัสดุจริงครบ 1 ชุด พร้อมหน่วยซื้อและ Data Sheet

- [ ] Productivity ทีมงาน ชั่วโมงปกติ และค่าแรงปกติครบ

- [ ] ทุกข้อมูลอ้างอิง Version, Evidence, Approver และ Effective Date
- [ ] ไม่มีค่าประมาณหรือค่าตัวเลขสมมติ
