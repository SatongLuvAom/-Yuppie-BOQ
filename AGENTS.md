## Core Rules

- Follow the nearest `AGENTS.md`; it may narrow these rules.
- Edit only paths explicitly assigned in the task brief.
- Keep changes small, typed, testable, and dependency-light.
- Do not start Phase 1 features during Phase 0.
- Never invent prices, labor rates, productivity values, allowances, or standards.
- Label every test or fixture datum `DEMO_ONLY`.
- Record durable architecture changes as ADRs; do not hide decisions in code.
- Before handoff, run the relevant checks and report failures honestly.
